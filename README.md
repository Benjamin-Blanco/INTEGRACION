# Material de Derecho de la Integración

Este repositorio reúne los materiales de la asignatura "Derecho de la Integración". Incluye presentaciones en formato PPTX y versiones HTML de cada sesión, además de un índice principal.

## Contenido principal
- **index.html**: página de inicio con acceso al material completo.
- **Primera a Décima Sesión**: archivos HTML y PPTX con el contenido de cada sesión (por ejemplo, `Primera Sesion.html` y `Primera Sesion (Temas 1 y 2) (1).pptx`).
- **Categorías**: archivo `categorias.html` con material de referencia adicional.
- **Documentos de apoyo**: archivo PDF y documentos Word con guías y planificación.

## Cómo usar el material
1. Abre `index.html` en tu navegador para navegar por todas las sesiones.
2. Descarga las presentaciones PPTX si necesitas editarlas o presentarlas en clase.
3. Consulta las versiones HTML para revisión rápida en cualquier dispositivo.

## Sugerencias para contribuir
- Mantén la nomenclatura consistente entre las versiones HTML y PPTX de cada sesión.
- Si agregas una nueva sesión, incluye tanto la versión HTML como la presentación correspondiente y enlázalas desde `index.html`.
- Para cambios pequeños (por ejemplo, correcciones ortográficas), edita directamente la versión HTML y, si aplica, actualiza la PPTX.
